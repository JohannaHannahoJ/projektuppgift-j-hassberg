# Projektuppgift – Programmering i C#.NET DT071G

Projektet är slutuppgiften för kursen Programmering i C#.NET som ges vid Mittuniversitetets Webbutvecklingsprogram
**Genomförd av: joha2102**

## Projektbeskrivning
Syftet med projektet är att utveckla en konsolbaserad applikation i C# och .NET som hjälper enskilda näringsidkare att sköta sin löpande bokföring. 

Applikationen ska ge användaren möjlighet att hantera en kontoplan, registrera och visa verifikat samt lagra bokföringsdata i en relationsdatabas.

Programmet är inte tänkt att vara ett färdigt system som uppfyller alla juridiska krav på bokföring utan en grund som ska kunna utvecklas vidare efter kursen.
